# Asignación de Turnos Médicos del Hospital Santa Lucía de Fredonia – Proyecto DEMO

Este repositorio contiene un prototipo funcional desarrollado como parte del ACA 3.

El DEMO permite:
- Solicitud de turnos médicos (form.html)
- Confirmación automática del turno (result.html)
- Visualización de turnos en panel administrativo (admin.html)

Tecnologías utilizadas:
- HTML5
- CSS (Tailwind)
- JavaScript

Notas:
- Los datos son simulados.
- El sistema no cuenta con backend.
- El objetivo es demostrar la solución técnica propuesta.
